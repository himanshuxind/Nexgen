# NexGen Arcade

NexGen Arcade is an independent technology and innovation venture building experimental software, hardware, AI, robotics, computer vision, IoT, assistive technology, and smart-agriculture projects.

**Website:** https://nexgenarcade.vercel.app  
**GitHub:** https://github.com/himanshuxind/Nexgen

## Featured projects

### NEURODRIVE
NEURODRIVE is an experimental eye-controlled smart mobility and assistive-technology project exploring computer vision, eye interaction, embedded systems, motor control, and obstacle detection.

**Project:** https://nexgenarcade.vercel.app/projects/neurodrive

### G-AN
G-AN is an experimental smart-agriculture project exploring AI, sensors, IoT, connected systems, and intelligent analysis for farming applications.

**Project:** https://nexgenarcade.vercel.app/projects/g-an

## Website technology

The NexGen Arcade website is built with React and TypeScript and uses TanStack Start/Router, Vite, Three.js, GSAP, Tailwind CSS, and reusable components.

## Repository structure

- src/routes/ — application and project routes
- src/components/ — UI, animation, and interactive components
- src/data/projects.ts — structured project metadata
- src/assets/ — brand and project assets
- public/ — static assets and crawler configuration

## Development

    git clone https://github.com/himanshuxind/Nexgen.git
    cd Nexgen
    npm install
    npm run dev
